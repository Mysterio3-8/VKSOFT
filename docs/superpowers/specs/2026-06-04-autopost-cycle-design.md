# Дизайн: Цикл автопостинга

**Дата:** 2026-06-04  
**Статус:** Approved  
**Цель:** объединить существующие скачивание, антиплагиат, отложенную публикацию и аналитику в один повторяемый цикл.

---

## Суть

Пользователь не хочет отдельную новую систему вместо текущего бота. Нужна умная обертка над тем, что уже работает:

```
запуск цикла -> скачать посты -> применить текущую обработку/антиплагиат ->
поставить отложенные на 1-2 дня -> собрать статистику -> предложить/применить настройки ->
следующий запуск цикла
```

Публикация остается через текущий механизм отложенных постов. Внешние модели не используются. Все обучение строится на алгоритмах и статистике.

---

## Правила

- Не ломать текущий продовый поток скачивания и публикации.
- Использовать существующие источники, фильтры, антиплагиат, phash, watermark и publish worker.
- Горизонт отложки настраивается, базово 1-2 дня.
- Бот не пытается ставить посты на год вперед.
- После цикла пользователь запускает анализ, бот корректирует настройки или показывает рекомендации.
- Коррекция без внешних моделей: только статистика просмотров, лайков, репостов, комментариев, часов публикации и источников.

---

## UI

Отдельная страница должна называться по смыслу `Цикл автопостинга`.

Основные блоки:

- `Запустить цикл` — скачать и поставить отложку на выбранный горизонт.
- `Горизонт` — 1 или 2 дня, плюс свое значение.
- `Постов в день` — сколько постов планировать.
- `Dry-run` — показать план без изменений.
- `Анализ` — посмотреть статистику и рекомендации.
- `Применить рекомендации` — обновить настройки профиля.

---

## Коррекция настроек

Анализ должен предлагать:

- лучшие часы публикации;
- постов в день;
- минимальный порог качества/вовлеченности;
- сильные и слабые источники;
- предупреждения по пустой очереди, токенам и лимитам.

На первом этапе достаточно алгоритмических рекомендаций и безопасного применения простых настроек:

- `publishing_settings.posts_to_publish`;
- `publishing_settings.publish_delay_min`;
- `publishing_settings.publish_delay_max`;
- `peak_hours.hours`;
- `autopost_cycle.horizon_days`;
- `autopost_cycle.posts_per_day`.

---

## Критерии готовности

- Есть отдельная страница цикла автопостинга.
- Можно запустить dry-run цикла.
- Можно запустить реальный цикл через существующий download/publish flow.
- Можно получить анализ и рекомендации без внешних моделей.
- Можно применить рекомендации к настройкам профиля.
- Старые кнопки скачивания и публикации продолжают работать.
