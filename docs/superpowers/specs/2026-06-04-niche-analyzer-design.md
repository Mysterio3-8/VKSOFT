## Цель

Добавить в бот инструмент анализа VK-ниш: находит популярные сообщества по ключевым словам или автоматически, оценивает потенциал каждой ниши и выдаёт рейтинг в Web UI. Цель — помочь пользователю быстро найти перспективные ниши и добавить лучшие сообщества как источники для репостинга.

## Поток данных

```
Пользователь вводит ключевые слова → POST /api/niche/scan
    ↓
niche_analyzer.py запускает фоновый воркер
    ↓
Для каждого ключевого слова:
    vk.groups.search(q=keyword, count=20) → список сообществ
    vk.wall.get(owner_id=-group_id, count=20) → последние посты
    ↓
Подсчёт скора для каждого сообщества
    ↓
Группировка по нишам (по ключевому слову)
    ↓
Сохранение в app_state.last_niche_results
    ↓
GET /api/niche/results → таблица в UI
```

---

## Скор-формула

```python
score = avg_members * (avg_likes_per_post / max(avg_posts_per_week, 1)) * activity_factor
```

Где:
- `avg_members` — количество подписчиков сообщества
- `avg_likes_per_post` — среднее число лайков на пост (последние 20 постов)
- `avg_posts_per_week` — среднее число постов в неделю
- `activity_factor` — доля постов за последние 7 дней от последних 20 (0.0–1.0)

Скор нормализуется до 0–100 внутри выборки.

## API

### `POST /api/niche/scan`

**Body:**
```json
{
  "keywords": ["фитнес", "юмор", "авто"],
  "auto": false
}
```

Если `auto: true` — игнорирует `keywords`, использует встроенный список популярных ниш (20 категорий: юмор, фитнес, авто, кулинария, путешествия, мотивация, технологии, животные, красота, спорт, музыка, кино, игры, бизнес, психология, дети, мода, здоровье, новости, природа).

**Response:**
```json
{ "status": "started" }
```

**Ошибки:** 400 если уже идёт сканирование.

---

### `GET /api/niche/results`

**Response:**
```json
{
  "status": "done",  // "running" | "done" | "idle" | "error"
  "progress": 100,   // 0–100
  "results": [
    {
      "keyword": "фитнес",
      "communities": [
        {
          "id": 12345,
          "name": "Фитнес и Здоровье",
          "screen_name": "fitness_health",
          "members": 500000,
          "avg_likes": 1200,
          "posts_per_week": 14,
          "activity_factor": 0.85,
          "score": 87.3
        }
      ],
      "top_community": { ... },
      "avg_score": 54.2
    }
  ]
}
```

---

### `POST /api/niche/add-source`

**Body:**
```json
{ "community_id": "12345" }
```

Добавляет сообщество в `sources` текущего профиля (аналогично существующему `/api/sources`). Возвращает 400 если источник уже добавлен.

## Ограничения и грабли

- **VK rate limit:** `groups.search` + `wall.get` по 20 сообществ на ключевое слово — при 20 ключевых словах это ~60 запросов. Нужна пауза 0.3–0.5 сек между запросами (аналогично `vk_call_safe` в `vk/api.py`).
- **Закрытые группы:** `wall.get` вернёт ошибку 15 (нет доступа) — пропускаем, не считаем в скор.
- **Нет данных о росте подписчиков:** VK API не отдаёт историю подписчиков без специальных прав. Используем `activity_factor` как косвенную метрику роста.
- **Токен:** Используем `user_token` (он же используется в `vk/api.py` для `get_vk_api()`).
- **Одновременность:** Пока идёт сканирование — блокируем повторный запуск через `app_state.is_niche_scanning`.

## Что НЕ входит в v1

- Сравнение ниш между запусками (трекинг динамики)
- Фильтрация по возрасту аудитории, географии
