# /update-docs

Автоматически анализирует изменения в коде и обновляет CLAUDE.md.

## Использование

```bash
# Полный анализ проекта и обновление CLAUDE.md
/update-docs

# После добавления нового сервиса/воркера/маршрута
"Обнови документацию — добавил новый сервис analytics.py"
```

## Что проверяет и обновляет

1. **Новые API маршруты** → добавляет в раздел `api/`
2. **Новые воркеры** → описание в "Ключевые воркеры"
3. **Изменения AppState** → обновляет "AppState синглтон"
4. **Новые зависимости** → обновляет `requirements.txt` в документе
5. **Обнаруженные проблемы** → добавляет в "Известные грабли"
6. **Завершённые задачи** → обновляет "Checkpoint"

## Результаты

После выполнения:
- CLAUDE.md обновлён
- Все разделы актуальны
- Timestamp обновлён
- Готово к коммиту

## Когда использовать

- После добавления новой функции
- После рефакторинга крупной части кода
- Перед push на гит
- После исправления известного бага (обновить его статус)

## Auto-update через гит

**Внимание:** CLAUDE.md также автоматически обновляется при коммите, если были изменены ключевые файлы:
- `main.py`, `config.py`, `requirements.txt`
- Файлы в `api/`, `services/`, `workers/`, `vk/`

Коммит автоматически обновит Checkpoint и дату.
