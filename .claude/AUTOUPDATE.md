# CLAUDE.md Auto-Update System

## ✅ Что установлено

Git hooks для автоматического обновления CLAUDE.md:

### 1. post-commit hook
**Когда:** После каждого коммита
**Что делает:** Обновляет CLAUDE.md если были изменены ключевые файлы

```bash
# Триггерные файлы (при изменении — обновляется CLAUDE.md):
- main.py
- config.py
- requirements.txt
- api/*.py
- services/*.py
- workers/*.py
- vk/*.py
```

**Автоматические обновления:**
- `## Checkpoint (ДАТА)` → текущая дата/время
- `**Дата обновления:** ДАТА` → текущая дата/время

### 2. pre-push hook
**Когда:** Перед каждым `git push`
**Что делает:** Проверяет что CLAUDE.md валидна

**Проверки:**
- ✓ CLAUDE.md существует
- ✓ Все обязательные разделы присутствуют
- ✓ Файл начинается с markdown заголовка
- ✓ Нет TODO/FIXME маркеров

Если что-то не так — push блокируется до исправления.

## 🔄 Как работает

### Сценарий 1: Редактируешь api/new_route.py
```bash
git add api/new_route.py
git commit -m "feat: add new endpoint"

# Автоматически:
# 1. Hook видит что api/*.py изменился
# 2. Обновляет Checkpoint в CLAUDE.md на текущую дату
# 3. Добавляет CLAUDE.md в коммит (amend)
```

### Сценарий 2: Редактируешь фронтенд (не триггер)
```bash
git add frontend/index.html
git commit -m "style: update UI colors"

# Hook видит что frontend/ изменился
# Это НЕ триггерный файл → CLAUDE.md не обновляется
# Коммит идёт как обычно
```

### Сценарий 3: Готов к push
```bash
git push

# Перед push'ем:
# 1. Hook проверяет CLAUDE.md
# 2. Убеждается что все разделы есть
# 3. Если OK → push идёт
# 4. Если NOT OK → push блокируется с ошибкой
```

## ⚙️ Технические детали

### Post-commit hook
```bash
# Файл: .git/hooks/post-commit
# Язык: bash
# Выполняется: после каждого успешного коммита
# Timeout: нет (обычно 1-2 сек)
# Error handling: игнорирует ошибки (не ломает коммит)
```

**Что делает за кулисами:**
1. Получает список изменённых файлов из последнего коммита
2. Проверяет есть ли совпадения с триггерными файлами
3. Если да → обновляет timestamp в CLAUDE.md
4. Если CLAUDE.md изменился → добавляет его в коммит (amend)

### Pre-push hook
```bash
# Файл: .git/hooks/pre-push
# Язык: bash
# Выполняется: перед git push
# Timeout: нет
# Error handling: БЛОКИРУЕТ push если валидация не пройдена
```

**Что проверяет:**
1. CLAUDE.md существует (пусть на компьютере, хоть на гите)
2. Все обязательные разделы присутствуют
3. Файл валидный markdown


## 📊 Статистика

**Post-commit hook запущен:** автоматически при каждом коммите  
**Pre-push hook запущен:** автоматически перед каждым push  
**Ошибки:** логируются в консоль, не прерывают разработку

## 🚨 Проблемы и решения

### Проблема: Hook не запустился
```
Решение: Проверь что файл executable:
  chmod +x .git/hooks/post-commit
  chmod +x .git/hooks/pre-push
```

### Проблема: Pre-push блокирует push
```
Решение: Проверь CLAUDE.md валидность:
  - Все ли разделы присутствуют?
  - Начинается ли с # ?
  - Нет ли TODO/FIXME ?
  
Исправь и попробуй ещё раз.
```

### Проблема: Post-commit в Windows не работает
```
Решение: Git на Windows может использовать CRLF вместо LF
  git config core.filemode false
  # Переустанови hooks
```
