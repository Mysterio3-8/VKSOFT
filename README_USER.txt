VK POST BOT - instrukciya polzovatelya

1. Zapusk
   Zapusti start.bat ili otkroy http://localhost:8000

2. Nastroyki VK
   Vo vkladke Settings ukazhi User token, Group token i Group ID.

3. Istochniki
   Vo vkladke Channels dobav VK community ID istochnikov.

4. Ruchnye operacii
   Na glavnom ekrane est dve otdelnye knopki:
   - Skachat vse: zagruzit posty iz aktivnyh VK-istochnikov.
   - Publikovat posty: opublikovat gotovuyu ochered.

Vazhno:
- Vidzhety, prilozheniya, avtopiloty i Telegram-uvedomleniya udaleny.
- Dlya raboty 24/7 nuzhen VPS ili vklyuchenny kompyuter.
- Oshibki smotri vo vkladke Logs.
